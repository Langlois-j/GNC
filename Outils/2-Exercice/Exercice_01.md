# Exercice : VS Code & Terminal

## Exercice 1 — VS Code
Tu as 5 occurrences du même mot à renommer dans un fichier. Quel raccourci utilises-tu pour les sélectionner toutes en une fois ?

## Exercice 2 — VS Code
Tu veux dupliquer une ligne de code juste en dessous d'elle-même, sans copier-coller manuellement. Quel raccourci ?

## Exercice 3 — Terminal
Écris la commande pour trouver tous les fichiers `.py` contenant le mot `TODO` dans un projet, récursivement.

## Exercice 4 — Terminal
Comment retrouver rapidement une commande `git` que tu as tapée il y a 20 commandes, sans faire défiler tout l'historique manuellement ?
