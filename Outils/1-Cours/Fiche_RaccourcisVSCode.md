# Fiche : Raccourcis VS Code essentiels

## 📌 Sélection & édition
| Raccourci (Windows) | Action |
|---|---|
| `Ctrl + D` | Sélectionner l'occurrence suivante du mot |
| `Ctrl + Shift + L` | Sélectionner toutes les occurrences |
| `Alt + Clic` | Ajouter un curseur multiple |
| `Ctrl + Shift + K` | Supprimer la ligne entière |
| `Alt + ↑ / ↓` | Déplacer la ligne vers le haut/bas |
| `Shift + Alt + ↓` | Dupliquer la ligne |

## 📌 Navigation
| Raccourci | Action |
|---|---|
| `Ctrl + P` | Recherche rapide de fichier |
| `Ctrl + Shift + P` | Palette de commandes |
| `Ctrl + Tab` | Basculer entre les fichiers ouverts |
| `F12` | Aller à la définition |
| `Alt + ←` | Revenir en arrière |

## 📌 Terminal intégré
| Raccourci | Action |
|---|---|
| `` Ctrl + ` `` | Ouvrir/fermer le terminal |
| `Ctrl + Shift + 5` | Diviser le terminal |

## ✅ À retenir
`Ctrl + Shift + P` (palette de commandes) est le raccourci le plus polyvalent : quasi toutes les actions VS Code y sont accessibles.
