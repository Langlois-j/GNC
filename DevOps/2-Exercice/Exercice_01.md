# Exercice : Docker & Kubernetes

## Exercice 1 — Dockerfile
Écris un Dockerfile minimal pour une application Node.js qui écoute sur le port 3000 (fichier d'entrée : `server.js`).

## Exercice 2 — Docker, vrai/faux
a) Une image Docker peut être utilisée pour lancer plusieurs conteneurs — Vrai/Faux ?
b) `docker ps` liste toutes les images téléchargées — Vrai/Faux ?
c) Un conteneur arrêté peut être relancé sans perdre son état — Vrai/Faux ?

## Exercice 3 — Kubernetes, vocabulaire
Associe chaque terme à sa définition :
`Pod` · `Deployment` · `Service` · `kubectl`

1. CLI pour piloter le cluster
2. Expose des pods avec une IP stable
3. Plus petite unité déployable
4. Décrit le nombre de répliques souhaitées

## Exercice 4 — Mise en pratique
Sur [Killercoda](https://killercoda.com/), lance un scénario "Kubernetes Playground" et exécute `kubectl get nodes`. Combien de nœuds vois-tu ?
