# Exercice 04 : Structures de données (chaînes, listes, tuples, dictionnaires)

## Exercice 1 — Chaînes
Demande une phrase à l'utilisateur, affiche-la en majuscules, puis compte le nombre de fois où la lettre "e" apparaît.

## Exercice 2 — Listes
Crée une liste de 5 courses, ajoute un article, retire-en un par son nom, puis trie et affiche la liste finale.

## Exercice 3 — Tuples
Écris une fonction `coordonnees()` qui renvoie un tuple `(x, y)`. Récupère ces valeurs dans deux variables distinctes.

## Exercice 4 — Dictionnaires
Crée un dictionnaire représentant une fiche contact (`nom`, `telephone`, `email`). Ajoute une clé `ville`, puis affiche toutes les clés/valeurs avec une boucle.

## Exercice 5 — Combinaison
À partir d'une liste de dictionnaires représentant des utilisateurs (`nom`, `age`), affiche le nom de l'utilisateur le plus âgé.
