# Correction 02 : Les variables

## Exercice 1
`majeur` est déclarée avec `const`, qui interdit toute réaffectation après l'initialisation — JavaScript lève une `TypeError: Assignment to constant variable.`

## Exercice 2
```javascript
const prenom = "Julien";
let anneeNaissance = 1996;
const estMajeur = true;
let tailleM = 1.78;
```

## Exercice 3
```javascript
const prenom = "Julien";
const age = 30;
console.log(`${prenom} a ${age} ans`);
```
