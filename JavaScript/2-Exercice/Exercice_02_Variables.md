# Exercice 02 : Les variables

## Exercice 1 — const vs let
Explique en une phrase pourquoi ce code lève une erreur :
```javascript
const majeur = 18;
majeur = 21;
```

## Exercice 2 — Types simples
Déclare les variables suivantes avec le mot-clé adapté (`const`/`let`) et le bon type : `prenom` (texte), `anneeNaissance` (entier), `estMajeur` (booléen), `tailleM` (décimal).

## Exercice 3 — Template literals
Affiche `"Julien a 30 ans"` en utilisant un template literal, à partir des variables `prenom = "Julien"` et `age = 30`.

## Exercice 4 — Tableau
Crée un tableau `notesClimbing` contenant 8 notes d'entraînement sur 20, avec au moins une valeur `"abs"` (séance manquée).

## Exercice 5 — Tableau de tableaux
Crée un tableau `planningSemaine` où chaque ligne représente un jour `["Lundi", "Escalade", "2h"]`, pour 3 jours différents.

## Exercice 6 — Objet
Déclare un objet `voiture` avec les propriétés `marque`, `modele`, `annee`, `electrique` (booléen), `autonomieKm`.
