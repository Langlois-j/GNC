# Exercice 05 : Les fonctions

## Exercice 1 — Deviner un nombre aléatoire
Créez :
1. Une fonction `getRandomInt(max)` qui renvoie un entier aléatoire entre 0 et `max` (inclus).
2. Une fonction `isRight(n)` qui renvoie `true`/`false` selon que `n` correspond à la solution.
3. Une fonction `guess()` qui demande un nombre à l'utilisateur (`prompt`) et renvoie `true`/`false` via `isRight`.

Utilisez une boucle pour laisser **3 essais** à l'utilisateur, avec un message de victoire ou de défaite.

## Exercice 2 — Nombre premier
Créez une fonction `isPremier(n)` qui renvoie `true` si `n` est un nombre premier (divisible uniquement par 1 et lui-même), `false` sinon. Rappel : 0 et 1 ne sont pas premiers.

Testez avec : 0, 1, 2, 3, 11, 12.
