# Exercice : Prompt Engineering, RAG, LLM

## Exercice 1 — Prompt Engineering
Réécris ce prompt flou pour le rendre précis et actionnable :
`"Aide-moi avec mon code Python"`

## Exercice 2 — RAG
Explique en 2-3 phrases pourquoi un chatbot RAG branché sur la documentation interne d'une entreprise hallucine moins qu'un LLM seul.

## Exercice 3 — LLM, vrai/faux
a) Un LLM "sait" ce qui est vrai ou faux — Vrai/Faux ?
b) Augmenter la température rend les réponses plus déterministes — Vrai/Faux ?
c) Le RAG nécessite de ré-entraîner le modèle — Vrai/Faux ?

## Exercice 4 — Mise en pratique
